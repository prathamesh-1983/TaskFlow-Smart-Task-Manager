# TaskFlow Smart Task Manager

A calm, focused task manager for organizing daily work, deadlines, and priorities.

## Run it

Open `index.html` in a browser. Tasks are saved in that browser's local storage, so no account or server is needed.

## Features

- Daily, upcoming, important, completed, and all-task views
- Task deadlines, priorities, notes, search, and sorting
- Edit, complete, and delete actions
- Daily and weekly progress indicators
- List and compact layouts, with keyboard shortcuts for search (`/`) and new tasks (`Ctrl`/`Cmd` + `Enter`)
